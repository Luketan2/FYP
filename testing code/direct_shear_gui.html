⚠ Motor Swap Procedure

This tab drives a different motor on the same TMC5160. Unplugging a stepper while the driver is energised dumps the winding's stored energy into the output stage and will destroy it. Every time you change motors:

  1. Press Disable Driver below (or STOP) — EN goes high, no current flows.
  2. Switch off the motor supply (VM) at the PSU. The GUI cannot do this for you.
  3. Swap the motor connector.
  4. Confirm the correct run current for the motor now fitted, then power VM back on.

The motor is bolted to the table with a bare shaft, so it acts as a reaction-mass shaker: the rotor oscillates and the table feels the reaction as a torque couple about the shaft axis. Amplitude is set in microsteps because there is no leadscrew — the shaft angle above is the physical quantity. While vibration is active the firmware switches the driver to SpreadCycle with interpolation off (StealthChop cannot track reversals at this rate) and refuses shear-axis commands.

The original file is never modified — each conversion is written beside it as …_cal.csv.
